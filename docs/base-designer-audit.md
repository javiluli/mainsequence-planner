# Estado actual de `base-designer`

`/bases` ofrece un lienzo React Flow de estaciones y notas, **sin edges de React Flow**: piezas y rutas se dibujan dentro de nodos de estación. `model/catalog.ts` define huellas 14×14/30×30, piezas y capacidades nominales; `lib/` resuelve suelo, pasillos de dos celdas, ocupación, puertos, rutas y flujo dirigido; `src/store/base-designer.store.ts` guarda el diseño en memoria y hasta 50 instantáneas de deshacer; `ui/` integra paleta, lienzo, paneles y comparación informativa con Planner. - [ ] Modal de drones y marcador de entrada integrados, documentados y revisados manualmente; sin restos provisionales.
- [ ] Estaciones 14×14/30×30, puertas de seis celdas y pasillos de dos celdas coherentes con máquinas/cintas/dron; ninguna pieza ocupa pared o hueco.
