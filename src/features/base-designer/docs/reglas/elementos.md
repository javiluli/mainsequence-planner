## Límites de extensión

Un edificio nuevo con huella cuadrada, offsets regulares y comportamiento actual se añade al registro tipado con datos físicos verificados y Crafter real cuando proceda. No exige clase ni feature propia. Rectángulos, caras asimétricas o giro libre afectan G06/G07, selección, límites de grupo, puertos, previews y persistencia; requieren cambio de contrato explícito. Un tamaño de arte o categoría de catálogo no concede esos comportamientos.
