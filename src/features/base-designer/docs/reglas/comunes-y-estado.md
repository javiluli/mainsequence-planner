# Reglas comunes y estado confirmado

[Índice y convenciones](README.md). Estas reglas pertenecen a varias familias; sus particularidades se desarrollan en [Elementos](elementos.md), [Logística](logistica.md) e [Interacciones](interacciones.md). Confirmada indica evidencia de implementación, no exactitud de una simulación del juego.

## Extender estas reglas

Modificar tamaño, forma, coordenadas o apoyo exige seguir G01–G07 hasta selección, clipboard, rutas, persistencia y canvas. Modificar sólo arte no permite cambiar esos contratos. Las decisiones del resultado final son distintas del predicado conservador de captura individual; ver E07 y Q6 en el [índice](README.md).
